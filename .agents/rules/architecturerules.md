ARCHITECTURE CHANGE PROTOCOL

Before changing any of the following:

- database
- blockchain
- framework
- storage system
- authentication system
- event bus
- streaming protocol
- token model

the agent MUST:

1. Explain the problem.
2. Explain the proposed solution.
3. Explain alternatives.
4. Explain migration impact.
5. Explain effect on deadline.
6. Wait for explicit approval.

Never silently perform architectural migration.
